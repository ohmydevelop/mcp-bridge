# 运维与回滚

- `GET /healthz` 检查数据库可用性。`bridge_get_status` 返回积压和失败数；其 recent_changes 可查看修改及游标缺口。数据库和事件历史会随使用增长，应监测数据卷空间。
- 冷备份时停止常驻进程，复制整个私有状态目录，包括 SQLite、包快照和实例数据。单独保管主密钥及环境凭证。恢复时把副本放入权限 0700 的空目录，使用同一主密钥与原上游配置启动；进程将重建 socket，并继续处理待投递记录。避免让旧实例和恢复实例同时向同一自动化端点投递。
- 使用 `bridge_update_source` 传入 package_path、patch 和当前 revision 安装新版插件。回滚时绑定此前保留的 digest。若新连接探测失败，已有实例继续服务。外部 CLI 及其依赖需在服务账户环境中可执行。
- Agent 添加的 stdio 程序拥有服务账户的操作系统权限。系统服务模板使用独立账户。HTTP token、主密钥、目标 origin 和网络暴露范围属于部署边界，不能通过普通 Agent 的 MCP tool 修改。
